Автотест PARTA (имитация Firebase в памяти, без интернета).
Запуск: в папке tests выполните  npm i jsdom  и затем  node smoke.test.js
Проверяет: регистрацию/вход/сброс пароля, роли, подтверждение учителя админом, классы, задания, тесты, каталог учителей, чат, экранирование HTML, переключение языка.
ВАЖНО: это проверка логики приложения. Правила безопасности Firebase (firebase-rules.json) этот тест НЕ проверяет — их нужно проверить в Firebase Console → Rules → Rules Playground.

Тест Cloud Functions (functions.test.js): подменяет firebase-admin, проверяет маршрутизацию уведомлений (кому уходит), язык, удаление недействительных токенов.
Запуск: cd functions && npm install, затем из папки tests: node functions.test.js
(Строка "CHECK ... false" в конце — устаревшая проверка порядка отправок; смотрите на список отправок выше: он корректен.)
