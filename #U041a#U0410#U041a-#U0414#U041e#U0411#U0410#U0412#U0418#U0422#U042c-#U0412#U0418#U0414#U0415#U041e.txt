БЫСТРЫЙ СПОСОБ (проверить ролик за 10 секунд)
Откройте сайт с ?admin в адресе, например  ваш-сайт.netlify.app/?admin  (или index.html?admin),
зайдите в нужный урок, вставьте ссылку на YouTube в поле и нажмите «Добавить видео».
Видео появится сразу, но только в вашем браузере. Чтобы оно появилось у всех, нажмите
«Копировать строку для videos.json», вставьте её в файл videos.json и загрузите папку на Netlify заново.

КАК ДОБАВИТЬ ВИДЕО В УРОКИ (без программирования)

1) Загрузите ролик на YouTube (лучше "Доступ по ссылке", не "Приватный") и скопируйте ссылку.
2) Откройте файл videos.json в блокноте.
3) Добавьте строку. Ключ = предмет-класс:номер урока (нумерация с 0). Примеры:
     "alg-8:0": { "url": "https://youtu.be/XXXXXXXXXXX" },
     "math-3:1": { "url": "https://youtu.be/YYYYYYYYYYY", "title": { "ru": "Дроби", "uz": "Kasrlar" } },
     "geom-*:2": { "url": "https://youtu.be/ZZZZZZZZZZZ" }      <- звёздочка = для всех классов
   Между строками нужна запятая, у последней строки запятой нет.
4) Список всех ключей: файл videos-plan.csv (откроется в Excel). Либо откройте сайт как
   ваш-сайт.netlify.app/?admin — в уроке без видео будет показан его ключ.
5) Сохраните и загрузите папку на Netlify заново (перетащите на вкладку Deploys).

СВОИ ФАЙЛЫ (mp4): положите в папку videos/ рядом с index.html и укажите "url": "videos/dars1.mp4".
Совет: YouTube экономит трафик Netlify (на бесплатном тарифе трафик ограничен), mp4 лучше только для коротких роликов.

ВИДЕО НА РАЗНЫХ ЯЗЫКАХ (русский и узбекский)
Сайт показывает ролик на языке, выбранном посетителем (RU/UZ). Чтобы добавить оба, допишите к ключу язык:
     "alg-8:0@ru": { "url": "https://youtu.be/XXXXXXXXXXX" },
     "alg-8:0@uz": { "url": "https://youtu.be/YYYYYYYYYYY" },
Ключ без @ подходит для обоих языков. Если для языка посетителя ролика нет, а на другом языке есть,
сайт покажет его с пометкой RU/UZ и подпишет, на каком он языке.
В файле videos-plan.csv для этого две колонки: «видео на русском» и «видео на узбекском».

БЫСТРЫЙ СПОСОБ ДЛЯ МНОГИХ УРОКОВ (через Excel)
1) Откройте videos-plan.csv в Excel. В колонки «видео на русском» и «видео на узбекском» впишите ссылки YouTube.
   (Можно раздать разным учителям по предметам, потом собрать в один файл.)
2) Сохраните как CSV.
3) Откройте videos-tool.html в браузере, выберите файл. Нажмите «Скачать videos.json».
4) Положите videos.json в папку сайта (рядом с index.html) и загрузите папку на Netlify.
Ролики из таблицы добавляются поверх тех, что уже вшиты в сайт.
