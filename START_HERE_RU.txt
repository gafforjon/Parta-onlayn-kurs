PARTA — КОМНАТЫ (русская инструкция)

1. Для работы общих комнат разместите содержимое этой папки на Netlify.
2. Netlify → Add new project → Import an existing project → GitHub.
3. Выберите репозиторий с этими файлами (файлы должны лежать в корне).
4. Build command: оставить пустым. Publish directory: .
5. Site configuration → Environment variables → Add a variable:
   Key: PARTA_TEACHER_CODE
   Value: придумайте длинный секретный код, известный только учителям.
6. Перезапустите публикацию (Deploys → Trigger deploy).
7. Откройте Netlify-ссылку, нажмите «Комнаты». Учитель вводит секретный код и название комнаты.
8. Ученик вводит выданный 5-значный код и своё имя на другом устройстве.

Важно: GitHub Pages не выполняет netlify/functions/rooms.mjs.
На GitHub Pages кнопка может отображаться, но общие комнаты работать не будут.
Не публикуйте секрет учителя в HTML/JS или в публичном репозитории.
Список учеников хранится на Netlify Blobs. Для больших классов нужна отдельная проверка нагрузки и прав доступа.
