# Parta — GitHub Pages

Этот проект публикуется на GitHub Pages. Netlify не нужен.

## Публикация
1. Загрузите **содержимое** этой папки в корень нового публичного репозитория GitHub (файл `index.html` должен быть в корне).
2. В Settings → Pages выберите Deploy from a branch → `main` → `/(root)` → Save.
3. Дождитесь появления ссылки `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Онлайн-комнаты (обязательно отдельное хранилище)
GitHub Pages — статический хостинг: сам GitHub не может хранить общие комнаты или синхронизировать учеников. Поэтому для **настоящих комнат между разными устройствами** необходимо один раз подключить Firebase Realtime Database. Это не Netlify и не собственный сервер.

1. Откройте https://console.firebase.google.com/ и создайте проект.
2. Authentication → Sign-in method → Anonymous → Enable.
3. Realtime Database → Create database. Выберите подходящий регион и режим с закрытыми правилами.
4. Вкладка Rules: вставьте содержимое `firebase-rules.json`, затем Publish. Проверьте правила перед использованием с реальными учениками.
5. Project settings → Your apps → Web app: скопируйте объект конфигурации Firebase.
6. Откройте `index.html`, найдите `const FIREBASE_CONFIG = { ... };` и замените `null` на скопированный объект `{ apiKey: ..., authDomain: ..., databaseURL: ..., projectId: ..., appId: ... }`. Это **публичная конфигурация**, не пароль администратора.
7. Сохраните файл и загрузите обновлённый `index.html` на GitHub.
8. Откройте сайт на двух устройствах: учитель создаёт комнату, ученик вводит код. Проверьте отображение ученика.

## Ограничения
- Без подключения Firebase интерфейс комнат есть, но общие комнаты не работают.
- Код учителя не используется: создатель комнаты определяется анонимной Firebase-сессией на его устройстве.
- Если учитель очистит данные браузера, он может потерять доступ к закрытию старой комнаты.
- 5-значные коды не являются секретными; не используйте реальные фамилии или чувствительные данные учеников.
- Это базовая реализация: до использования в школе стоит проверить безопасность, нагрузку и правила удаления старых комнат.
