PARTA — ОБЩИЕ ВИДЕО ДЛЯ ВСЕХ

1. Опубликуйте папку проекта на Netlify через Git-репозиторий (не обычным открытием index.html и не простым ZIP-перетаскиванием без сборки функций).
2. В настройках сайта Netlify → Environment variables создайте PARTA_ADMIN_PASSWORD со своим длинным уникальным паролем.
3. Убедитесь, что Netlify установил зависимости из package.json и опубликовал функцию netlify/functions/videos.mjs.
4. Откройте https://ВАШ-САЙТ.netlify.app/?admin=1, выберите класс, предмет и урок, вставьте YouTube-ссылку, нажмите «Сохранить для всех» и введите пароль.
5. Ученик открывает обычный адрес https://ВАШ-САЙТ.netlify.app/ — видео видно всем, поле редактирования скрыто.
6. Для русского и узбекского языка сохраняйте отдельные видео. Для видео нужен интернет, а YouTube должен разрешать встраивание.

ВАЖНО: Если просто открыть index.html на компьютере, общий сервер недоступен. Сохранение для всех требует публикации сайта с Netlify Functions и Netlify Blobs.
