Parta: видео встроены непосредственно в страницу урока, без ручного ввода ссылки. Для алгебры некоторых классов используются общие плейлисты; для отдельных тем — заранее указанные видео. Не для всех тем есть подтверждённый ролик на обоих языках. Для воспроизведения нужен интернет и разрешение автора на встраивание. Откройте index.html или опубликуйте папку на хостинге.
