Четвёртый проход (03.11.2026): каталог учителей и личные чаты (#/teachers)
- Учитель при входе заполняет профиль (имя, фамилия, предмет, классы с–по) и появляется в каталоге. Примеров-заглушек нет: учителя — реальные зарегистрированные пользователи.
- Каталог: поиск по имени, фамилии и предмету, фильтр по классу; карточка: предмет, имя и фамилия, классы, кнопка «Написать учителю». Несколько учителей одного предмета показываются отдельно.
- Чат ученик ↔ учитель: ID чата = ID учителя + «_» + ID ученика (имена не используются для идентификации, одинаковые имена не смешиваются). Сообщения в реальном времени, дата и время, счётчик непрочитанных, отметки ✓ / ✓✓ (прочитано), список чатов у учителя, адаптация под телефон.
- Правила Firebase: чат создаёт только ученик с выбранным учителем; читать и писать могут только двое участников; сообщения нельзя изменить или удалить; профиль учителя пишет только сам учитель (роль teacher).
- ОБЯЗАТЕЛЬНО заново опубликуйте firebase-rules.json.
- Не сделано: push-уведомления вне открытой вкладки, удаление и блокировка чатов, модерация (администратор не читает чаты), вложения, раздел «Найти комнату», тесты после уроков, тёмная тема.
- Важно: пользователи — школьники. Решите, кто модерирует переписку, и расскажите об этом в политике конфиденциальности.
