PARTA — GitHub Pages + Firebase

1. Распакуйте этот ZIP.
2. В репозитории GitHub откройте Code. Удалите старые файлы сайта, особенно старый index.html (если есть), и загрузите все файлы из этого архива в корень репозитория. Не загружайте ZIP как один файл.
3. Убедитесь, что index.html находится в корне, а не внутри вложенной папки.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Дождитесь успешного GitHub Pages deployment. Откройте сайт с Ctrl+Shift+R.
6. В окне создания комнаты должна быть надпись «Firebase · GitHub Pages». Если написано Netlify — открыта старая версия index.html или кеш браузера.
7. Firebase Authentication: Anonymous — Enabled. Realtime Database: правила из firebase-rules.json должны быть опубликованы.

ВНИМАНИЕ: вход по пятизначному коду не является приватной авторизацией: любой, кто узнал код, может прочитать комнату. Не используйте настоящие персональные данные учеников до усиления правил и проверки безопасности.
